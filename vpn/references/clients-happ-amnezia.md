# Клиенты Happ и Amnezia VPN

## Happ (iOS/Android)
- Поддерживает: VLESS, VMess, Trojan, Shadowsocks
- Поддерживает REALITY
- Формат подписок: base64
- Ссылка: http://192.168.0.17:2113/subscribe
- Настройка: Добавить подписку → вставить URL

## Amnezia VPN (iOS/Android/Desktop)
- Поддерживает: VLESS, OpenVPN, WireGuard, IKEv2
- Поддерживает стандартные base64 подписки
- Ссылка: http://192.168.0.17:2113/subscribe
- Настройка: Добавить сервер → по ссылке
