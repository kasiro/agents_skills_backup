# Парсер цен Пятёрочки

## Рабочие методы

### 1. proshoper.ru (акции по регионам) — РАБОТАЕТ

**URL:** https://novosibirsk.proshoper.ru/actions/pyaterochka/

Парсится через lightpanda. Показывает акции на текущую неделю с ценами.
Ограничение: только товары по акции, не весь ассортимент.

**Категории:**
- Фрукты, овощи
- Молоко, сыр, яйца
- Мясо, рыба, колбасы
- Сладости, выпечка, хлеб
- Макароны, крупы, мука

### 2. skidki-catalog.ru — РАБОТАЕТ

**URL:** https://skidki-catalog.ru/katalog-pyaterochka.php

Содержит категории товаров с ценами, но данные могут быть неполными.

### 3. edadeal.ru — стоит проверять

**URL:** https://edadeal.ru/novosibirsk/shops/pyaterochka

Агрегатор акций. Может показывать цены для города.

### 4. Прямой API 5ka.ru — НЕ РАБОТАЕТ

Библиотека pyaterochka_api блокируется ServicePipe/WAF.
Требуется обход через Playwright с антидетект-браузером.

## Порядок действий для получения цен

1. Загрузить proshoper.ru через lightpanda — получить акционные цены
2. Для товаров не в акции — оценить среднюю цену по рынку
3. Если нужны точные цены на все товары — рекомендовать приложение Пятёрочки
4. Указывать для каких цен есть точные данные, а для каких — оценка
