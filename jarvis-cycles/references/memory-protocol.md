# Memory Protocol (memory blocks)

Память J.A.R.V.I.S. = memory blocks (инструменты `memory_set` — полная перезапись, `memory_replace` — точечная правка, `memory_list` — список блоков). Блоки всегда загружены в системный промпт.

- **Блоки:** persona (личность), human (о сэре), project (архитектура/правила проекта), knowledge (технические знания), lessons (уроки).
- **Scopes:** global (кросс-проектно) + project (по проектам).
- **Права:** J.A.R.V.I.S. (primary) пишет в память НАПРЯМУЮ (memory_set/memory_replace). Делегирование general'у касается ТОЛЬКО файлов, НЕ памяти.
- **Консолидация знаний:** пересмотр memory blocks вручную (memory_set/memory_replace).
- См. скилл `how_use_memory` для инструкций.

## Блоки

1. **persona** — личность (характер, речь, юмор, принципы)
2. **human** — о сэре (предпочтения, привычки, ограничения)
3. **project** — архитектура/правила проекта (Rules, Architecture decisions, Gotchas)
4. **knowledge** — технические знания, паттерны, статистика
5. **lessons** — уроки (каждая ошибка/исправление сэра)

## Запись (каждое сообщение)
- Инструменты: `memory_set` (полная перезапись блока) или `memory_replace` (точечная правка блока)
- Формат записи: `- [YYYY-MM-DD] <содержание 1-2 строки>`
- Решения → блок project (Architecture decisions), открытия → knowledge, ошибки → lessons

Триггеры автозаписи (когда именно записывать) — см. cycle1.md → SAVE.

## Консолидация (конец сессии)
- Пересмотр memory blocks вручную через memory_set / memory_replace
- Никаких внешних скиллов/файлов для консолидации не используется

## 🚨 Права записи в память (CRITICAL)

| Агент | memory blocks |
|-------|---------------|
| **J.A.R.V.I.S. (я)** | ✅ да — пишу НАПРЯМУЮ (memory_set / memory_replace) |
| **general** | ❌ нет — в память не пишет (делегирование касается только файлов) |

**Правило:** J.A.R.V.I.S. пишет в память напрямую через memory_set / memory_replace.  
**Правило:** general память не пишет — ему делегируются только файловые операции.

## ✅ Pre-Flight Check перед записью в память

Перед записью мысленно ответь на три вопроса:

1. **Куда?** — какой блок (persona/human/project/knowledge/lessons) и scope (global/project)?
2. **Кто?** — я сам, напрямую (не делегирование).
3. **Что?** — значимое durable знание (правило, решение, ошибка, инсайт). Не очевидное.

Если хотя бы один ответ не совпадает → **СТОП** и пересмотри, что и куда пишешь.
