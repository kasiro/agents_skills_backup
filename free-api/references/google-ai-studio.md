# Google AI Studio (Gemini API) — Free Tier

| Параметр | Значение |
|----------|----------|
| **Endpoint** | `https://generativelanguage.googleapis.com/v1beta/` |
| **API Format** | Google AI SDK |
| **Auth** | API Key |
| **⚠️** | Данные используются для обучения вне UK/CH/EEA/EU |
