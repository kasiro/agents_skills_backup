# 🔆 Яркость экрана (DDC/CI)

Управление яркостью монитора через `ddcutil` (DDC/CI). Монитор Samsung SMB2330, VCP код `0x10` (Brightness), диапазон 0-100.

## Категория 8 — Скрипты яркости

| Команда | Скрипт | Что делает |
|---------|--------|------------|
| Показать яркость | `scripts/brightness_show.py` | Текущее значение яркости |
| Установить яркость | `scripts/brightness_set.py <0-100>` | Установить заданное значение (без аргумента — 50) |
| Сделать ярче | `scripts/brightness_up.py` | Увеличить на 10% (максимум 100) |
| Сделать темнее | `scripts/brightness_down.py` | Уменьшить на 10% (минимум 0) |

## ⚠️ Критично для этого монитора

1. **Монитор SMB2330 не подтверждает запись** → ВСЕГДА использовать флаг `--noverify` в `setvcp`. Без него запись молча не применяется (монитор не отвечает на VCP-запрос подтверждения).
2. **Работает БЕЗ `doas`** — udev-правила `60-ddcutil-i2c.rules` (GROUP=i2c + TAG+="uaccess") дают logind-ACL активному пользователю. kasiro в группу `i2c` НЕ добавлен — это нормально.
3. VCP-код: `0x10` (Brightness), диапазон значений 0-100.
4. Монитор подключён по DVI-I-1 (`/dev/i2c-0`), десктоп.

## Команды ddcutil напрямую

```bash
# Показать текущую яркость
ddcutil getvcp 10

# Установить яркость (ВСЕГДА с --noverify!)
ddcutil setvcp 10 60 --noverify

# Диагностика монитора
ddcutil detect
```

## Зависимости

```bash
doas pacman -S ddcutil
```

## Альтернатива (не физическая)

`gammastep` — гамма-фильтр (программное затемнение, не меняет подсветку монитора). `xrandr` на Wayland не работает.
