# Psychology Skill — Психология

Полный справочник по психологии с референсами. 23 темы, разбитые на 5 блоков.

**Триггеры**: психология, психолог, нарциссизм, ПРЛ, BPD, C-PTSD, КПТСР, травма,
КПТ, CBT, DBT, майндфулнес, привычки, прокрастинация, мотивация, эмоциональный
интеллект, EQ, социальная психология, привязанность, NVC, ненасильственное общение,
границы, стресс, сон, обучение, позитивная психология, деньги, зависимость,
аддикция, когнитивные искажения, принятие решений, культурная психология.

**Примеры**:
- "почему я срываюсь на близких и потом виню себя" → BPD + C-PTSD + splitting
- "помоги разобраться с прокрастинацией" → самосаботаж + привычки + мотивация
- "как ставить границы с матерью" → boundaries + NVC + attachment
- "как работает манипуляция" → тёмная триада + макиавеллизм
- "я не чувствую эмоций, только пустоту" → BPD + C-PTSD (affective dysregulation)
