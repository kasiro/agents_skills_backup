# 22. Принятие решений

## Две системы (Kahneman, 2011)

| System 1 | System 2 |
|----------|----------|
| Быстрый, автоматический | Медленный, усиленный |
| Интуитивный | Аналитический |
| Эмоциональный | Рациональный |
| Энергосберегающий | Энергозатратный |
| Ошибки — biases | Точнее, но устаёт |
| 95% наших решений | 5% (тяжёлая артиллерия) |

## Модели принятия решений

| Модель | Суть |
|--------|------|
| **Rational Choice** | Взвесить опции → выбрать max utility (идеал, в жизни так редко) |
| **Bounded Rationality** (Simon, 1956) | Ограниченная информация, время, когниция → satisficing |
| **Naturalistic Decision Making** (Klein, 1998) | Recognition-primed: эксперты узнают ситуацию → одно решение |
| **Dual Process** (Kahneman) | S1 → intuition → S2 проверяет (если успевает) |
| **Emotion-as-information** (Schwarz, 2012) | Эмоция сигналит о ситуации и сужает варианты |
| **Risk-as-feelings** (Loewenstein, 2001) | Эмоциональная реакция на риск ≠ рациональная оценка |

## Почему мы принимаем плохие решения

| Причина | Механизм |
|---------|----------|
| **Cognitive overload** | Слишком много опций → паралич / саботаж |
| **Framing effect** | 90% выживаемости vs 10% смертности — разная реакция |
| **Present bias** | «Мышь сейчас vs орел завтра» — переоценка немедленного |
| **Loss aversion** | Потеря = ~2× вес выигрыша (Kahneman & Tversky, 1979) |
| **Overconfidence** | Переоценка точности собственных прогнозов |
| **Groupthink** | Желание консенсуса подавляет альтернативы |
| **Affect heuristic** | «Нравится → значит безопасно / верно» |
| **Analysis paralysis** | Бесконечные данные → ни одного решения (overthinking) |

## Структура для сложных решений

```
1. Определи проблему (что я решаю?)
2. Собери опции (не менее 3)
3. Критерии: что важно? (5 факторов max)
4. Взвесь (каждый критерий × важность)
5. Выбери лучшее
6. Оцени неопределённость: что может пойти не так?
7. Реши: зафиксируй
```

## Принятие решений при ПРЛ / C-PTSD

| Проблема | Что происходит | Совет |
|----------|---------------|-------|
| **Impulsivity** | Решение без паузы (DSM-5, крит. 4) | Delay: 24h rule для серьёзных решений |
| **Identity instability** | «Я не знаю, что для меня важно» | Ценности (ACT) как компас |
| **Rejection sensitivity** | Решения, чтобы угодить | Пауза: «Я это делаю для себя или для?» |
| **Splitting** | «Оба варианта — говно / один идеален» | Pros & cons, экспертное мнение |
| **Overwhelm → avoidance** | Не могу решить → не решаю вообще | Satisficing: «достаточно хорошо» |
| **Fear of regret** | «А вдруг я пожалею?» → застыл | Принять: любое решение — не последнее |
