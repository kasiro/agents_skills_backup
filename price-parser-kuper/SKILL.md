# Парсер цен Купера

## Ограничения

- **kuper.ru** — Cloudflare-защита, прямого парсинга нет
- **kuper.ru/categories** — тоже заблокирован
- Цены **зависят от адреса** — нужно вводить конкретный адрес

## Разрешённые для индексации каталоги (из robots.txt)

Купер разрешает индексацию каталогов магазинов-партнёров:
- https://kuper.ru/5ka/c/ — товары Пятёрочки
- https://kuper.ru/magnit/c/ — товары Магнита
- https://kuper.ru/auchan/c/ — товары Ашана
- https://kuper.ru/perekrestok/c/ — товары Перекрёстка
- https://kuper.ru/lentagp/c/ — товары Ленты
- https://kuper.ru/metro/c/ — товары METRO

Но эти страницы также защищены антиботом.

## Методы получения цен

### 1. Через поисковые системы
Искать: `site:kuper.ru "название_товара" "цена"`
Использовать: lightpanda (Bing через fetch) для поиска проиндексированных страниц

### 2. Через агрегаторы-партнёры
Купер берёт товары из магазинов. Можно получить цены через:
- API Пятёрочки (pyaterochka_api) — для товаров из 5ka
- Агрегаторы Ленты, Ашана и т.д.
- К цене магазина добавить наценку Купера ~10-15%

### 3. Ориентировочные цены
Если точные цены недоступны, использовать среднерыночные с наценкой 12%.

## Наценка Купера
- К цене магазина-партнёра добавляется ~10-15%
- Доставка: бесплатно от 1500-2000₽ или ~150-200₽ за заказ
