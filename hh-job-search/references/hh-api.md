# HeadHunter API и модульный пакет

Проект: `~/Документы/python_projects/hh-agent/`
- `main.py` — единый CLI entry point
- `hh_api/` — модульный пакет (client, models, search, vacancy, apply, messages, history)
- `hh_vacancy.py` — парсер полной вакансии (выдаёт `description_text`)

Единый запуск всех команд: `uv run python main.py <команда>` (см. `commands.md`).

## Полное описание вакансии (hh_vacancy.py)

Для формата интервью нужно ПОЛНОЕ описание вакансии — получать через `hh_vacancy.py`
и показывать весь `description_text` целиком, не пересказывать кратко.

## Авторизация и работа с аккаунтом

Авторизация на HeadHunter даёт доступ к:
- **Истории откликов** — список вакансий, на которые сэр откликался
- **Чатам** — переписка с работодателями

Команды:
- `uv run python main.py login` — открывает браузер для ручной авторизации, сохраняет сессию в `hh_auth.json`
- `uv run python main.py history` — просмотр online-откликов с HH (живые данные)
- `uv run python main.py history --local` — просмотр из локального файла history.json (без сети)
- `uv run python main.py history --sync` — синхронизация истории с HH в локальный файл

Правила:
- `history` запускать при каждом поиске — держать историю свежей
- Чаты проверять, но НЕ отвечать — только сообщать сэру о новых сообщениях
- Если в чате новое сообщение от работодателя — показать сэру и спросить: «Ответить?»

## Проверка чатов и непрочитанных сообщений

При каждом запуске:
1. Запустить `uv run python main.py messages` для проверки чатов
2. Открыть https://hh.ru/applicant/negotiations через авторизованную сессию
3. Проверить бейджи непрочитанных сообщений
4. Если есть непрочитанные — прочитать и показать сэру
5. Проверить приглашения на собеседования — выделить их отдельно

**Правило:** Непрочитанные сообщения показывать ПЕРВЫМ делом, до предложения новых вакансий.

## Дополнительные проверки при запуске

- При каждом запуске ПРОВЕРЯТЬ непрочитанные сообщения в чатах HH — запускать скрипт проверки чатов. Если есть непрочитанные — сразу показывать сэру.
- Показывать приглашения на собеседования и предложения от работодателей в первую очередь — они важнее новых вакансий.
- **ЗАПРЕЩЕНО** использовать прокси и VPN для доступа к HH. Если HH недоступен — так и сообщить сэру.
