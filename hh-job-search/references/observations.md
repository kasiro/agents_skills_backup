# Наблюдения (observations.json)

Файл: `scripts/observations.json` (рядом со SKILL.md)

Файл для записей наблюдений, которые J.A.R.V.I.S. делает в процессе поиска работы.

## Когда записывать наблюдение

- После каждого поиска — что показал рынок, какие тенденции
- Когда сэр сообщает новые предпочтения — записать как наблюдение
- Когда находится паттерн/закономерность — записать вывод

## Формат записи

```json
{
  "id": 1,
  "date": "2026-07-03T09:35:00",
  "context": "При каких обстоятельствах сделано наблюдение",
  "observation": "Текст наблюдения",
  "tags": ["тег1", "тег2"]
}
```

## Обязательства

- Перед каждым поиском читать observations.json — учитывать прошлые наблюдения
- После каждого взаимодействия проверять: есть ли новое наблюдение для записи
- Записывать наблюдения — что узнал о рынке, предпочтениях сэра, паттернах
