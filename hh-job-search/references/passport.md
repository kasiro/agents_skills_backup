# Обстоятельства соискателя (passport.json)

Файл: `scripts/passport.json` (рядом со SKILL.md)

Хранит данные о соискателе, влияющие на фильтрацию вакансий.

## Пример

```json
{
  "has_military_id": false,
  "notes": "Нет военного билета — не подходят вакансии с обязательным военно-учётным требованием",
  "desired_position": "Python разработчик / Backend разработчик",
  "experience_years": 3,
  "key_skills": ["Python", "FastAPI", "PostgreSQL", "Docker", "Linux"],
  "employment_type": "full_time",
  "work_schedule": "remote",
  "location": "Новосибирск / удалённо"
}
```

## Как использовать

- При поиске вакансий учитывать `has_military_id: false` — отсеивать вакансии с пометкой «военнообязанным обязательно»
- Если пользователь хочет обновить — читать файл, предлагать изменить поля, сохранять
- Учитывать обстоятельства из passport.json при фильтрации (обязательно)
- Презентация: 10% удалёнка, 20% офис, 70% обычная работа
- Исключать продажи, банки, крупные корпорации, госструктуры
- Искать вакансии без опыта / с минимальным опытом
- Учитывать расположение: предпочтительно рядом с Горским 39 или у метро
