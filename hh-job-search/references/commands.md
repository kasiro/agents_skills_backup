# Справочник команд main.py

Единый entry point: `main.py` в проекте `~/Документы/python_projects/hh-agent/`.

**Запуск команд:**
```bash
cd ~/Документы/python_projects/hh-agent/
uv run python main.py <команда> [опции]
```

## Таблица команд

| Команда | Аргументы | Флаги | Описание |
|---------|-----------|-------|----------|
| `search` | `--query`, `--city`, `--page`, `--limit` | `--remote`, `--no-military`, `--json` | Поиск вакансий |
| `vacancy` | `url` | `--json` | Парсинг полной вакансии |
| `apply` | `url` | — | Автоотклик |
| `login` | — | — | Авторизация на HH |
| `history` | — | `--local` (из файла), `--sync` (синхр. с HH), `--quiet`, `--verbose` | Applied вакансии (по умолч. с HH онлайн) |
| `messages` | — | — | Проверка чатов |
| `is-applied` | `url` | `--verbose` | Проверка откликался ли на вакансию |

## Флаги поиска

- `--query` / `-q`: Поисковый запрос
- `--city` / `-c`: Город (по умолч. новосибирск)
- `--page` / `-p`: Номер страницы
- `--limit` / `-l`: Максимум результатов
- `--remote`: Только удалёнка
- `--no-military`: Фильтр военника
- `--json`: Вывод в JSON

## Регулярные действия

- Регулярно обновлять историю откликов — `uv run python main.py history --sync` для синхронизации с HH
- Следить за чатами — `uv run python main.py messages` для проверки новых сообщений от работодателей при каждом запуске
- `uv run python main.py history` запускать при каждом поиске — держать историю свежей
