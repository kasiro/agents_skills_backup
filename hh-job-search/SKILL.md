# HeadHunter Job Search Skill

Поиск работы на HeadHunter через Playwright. Подробная документация разбита на references
(progressive disclosure) — загружать по мере необходимости.

## Расположение файлов

| Файл | Путь |
|------|------|
| Данные соискателя | `scripts/passport.json` |
| Учёт вакансий | `scripts/history.json` |
| Наблюдения | `scripts/observations.json` |
| CLI entry point | `~/Документы/python_projects/hh-agent/main.py` |
| Модульный пакет | `~/Документы/python_projects/hh-agent/hh_api/` |

## Единый запуск команд

```bash
cd ~/Документы/python_projects/hh-agent/
uv run python main.py <команда> [опции]
```

## Обязательства (СТРОГО)

- **Перед предложением вакансии** проверять history.json — не предлагать повторно
  (по URL; если URL нет — по названию + компания; статусы applied/rejected/saved = НЕ ПРЕДЛАГАТЬ)
- **После ответа сэра** немедленно обновлять запись в history.json
- Хранить обстоятельства в passport.json и учитывать их при фильтрации
- При каждом запуске проверять непрочитанные сообщения в чатах HH (показывать первым делом)
- Предлагать 1-2 вакансии за раз в полном формате интервью (ПОЛНОЕ описание, ссылку сразу)
- Перед автооткликом (`apply`) проверять history.json — не откликался ли уже
- **ЗАПРЕЩЕНО** использовать прокси и VPN для доступа к HH
